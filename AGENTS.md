# AGENTS.md

## Commands

- Dev server: `npm run dev` (Turbopack). Site: http://localhost:3000
- Build: `npm run build`
- Lint: `npm run lint` (runs bare `eslint` with the flat config in `eslint.config.mjs`; `next lint` is gone)
- Typecheck: `npx tsc --noEmit` — there is no `typecheck` script and no tests in this repo
- Add shadcn UI components: `npx shadcn add <component>` (config in `components.json`)

## Stack quirks (Next.js 16 / React 19)

- Next.js 16.4.3 — APIs and conventions may differ from older training data. Local docs live in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`); verify against them before writing code.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `reactCompiler` (via `babel-plugin-react-compiler`). React Compiler changes memoization assumptions — don't add manual `useMemo`/`useCallback` boilerplate reflexively.
- Root layout uses Next 16 typed props: `RootLayout({ children }: LayoutProps<"/">)`.

## Styling & UI

- Tailwind CSS v4 — no `tailwind.config.*`. All theme tokens are CSS variables in `src/app/globals.css` (`@theme inline`, `@custom-variant dark`). Tailwind loads via the `@tailwindcss/turbopack` loader rule in `next.config.ts`; don't add a JS config file.
- shadcn components use style **`base-nova`**, built on **`@base-ui/react`** — NOT Radix. Do not paste Radix-based shadcn examples; APIs differ.
- Dark mode is class-based (`.dark` on `<html>`). `src/lib/theme-script.ts` is injected inline in `src/app/layout.tsx` before first paint to avoid FOUC; keep it in sync with `src/hooks/use-theme.ts`.
- Path alias: `@/*` → `src/*`.

## Architecture

- Single Next.js App Router app; all code in `src/`. UI primitives in `src/components/ui` (generated — prefer `shadcn add` over hand-editing), app code in `src/app`, shared code in `src/lib` and `src/hooks`.
- Auth is a **demo stub**: `src/lib/auth.tsx` holds in-memory client-side state with a hardcoded demo user; state intentionally resets on reload to stay hydration-safe. Don't add persistence or a real provider without being asked.
